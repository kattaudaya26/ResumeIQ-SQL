# AI Resume Screening and Candidate Management System

## 📌 Project Overview

The AI Resume Screening and Candidate Management System is a SQL-based database project developed using MySQL to simulate a real-world recruitment process. It helps manage candidate profiles, technical skills, job applications, interview details, resume evaluation scores, and final hiring decisions. The project demonstrates how relational databases can be used to organize recruitment data and generate meaningful insights through SQL queries.

---

## 🎯 Objectives

- Design a normalized relational database for recruitment management.
- Store and manage candidate information efficiently.
- Track job applications and interview performance.
- Evaluate resumes using screening scores.
- Analyze recruitment data using SQL.
